# مطاردة صقر الطريق

لعبة أركيد عربية للجوال: مطاردة شرطة + مهمات مدن + نيترو + درع + كومبو.

## الفكرة
بدل لعبة تفادي بسيطة، اللاعب الآن يدخل مطاردة مستمرة:
- مؤشر الشرطة يرتفع تدريجياً.
- التصادم لا ينهي الجولة دائماً، لكنه ينقص الصحة ويرفع المطاردة.
- كل مدينة لها مهمة: عملات، كومبو، نيترو، مسافة.
- بوابة مهمة كل عدة ثوانٍ: النجاح يعطي مكافأة ومدينة جديدة، والفشل يقرّب الشرطة.
