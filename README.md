# صقر الطريق

لعبة أركيد عربية سعودية للجوال، مصممة لتكون أسرع وأكثر تشويقاً من النسخة السابقة.

## المميزات
- حركة لمس مباشرة بين 3 مسارات.
- عقبات وزحام متزايد السرعة.
- عملات، بوست، كومبو، Near-miss score.
- مشاركة النتيجة.
- مكان إعلان مستقبلي.
- SEO و PWA و Privacy.

## التشغيل
npm install
npm test
npm run build
npm run preview
