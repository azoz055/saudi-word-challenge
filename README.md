# تحدي كلمات السعودية

لعبة كلمات عربية سعودية خفيفة للجوال، مصممة لتوليد زيارات ومشاركة اجتماعية وإضافة إعلانات لاحقاً.

## التشغيل
npm install
npm test
npm run build
npm run preview

## monetization
تم تجهيز أماكن إعلانات Placeholder. لتفعيل الدخل تحتاج حساب Google AdSense أو شبكة إعلانات، ثم استبدال placeholders بكود الإعلانات بعد الموافقة.
