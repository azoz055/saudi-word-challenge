# رادار السوق السعودي

موقع عربي RTL لمتابعة الأسهم السعودية عبر فريق إيجنتات:

- لوحة حالة السوق السعودي.
- بحث الشركات بالاسم والرمز والقطاع.
- محفظة تجريبية محفوظة في المتصفح.
- تحليلات مضاربة: RSI، EMA، حجم نسبي، دخول، وقف، أهداف، Risk/Reward.
- أخبار سياسية وسوقية مؤثرة.
- رصد التوصيات المتداولة بين الناس مع تحذير الشائعات.
- صفحة فريق الإيجنتات وحالة كل دور.
- تحديث بيانات مجدول عبر GitHub Actions إلى `public/data/market.json` ثم نشر GitHub Pages.

> تنبيه: المنصة تحليل آلي لأغراض البحث والمتابعة فقط وليست توصية مالية أو دعوة للبيع أو الشراء.

## التشغيل المحلي

```bash
npm install
npm run update:data
npm test
npm run build
npm run preview
```

## النشر

الـ workflow في `.github/workflows/refresh-and-deploy.yml` يحدث البيانات ويبني الموقع وينشر `dist` على فرع `gh-pages`.
